Install in a minute

Your wallets come with you: install Phantom, Solflare or Backpack from the Chrome Web Store inside STRATA and import your wallet as usual.

Windows

  1. Open strata-…-win-x64.exe.
  2. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.
  3. STRATA opens when it's installed and adds itself to the Start menu.

macOS

  1. Open the .dmg and drag STRATA to Applications.
  2. The first time, right-click STRATA in Applications and choose Open.
  3. Not sure which Mac you have? Apple menu → About This Mac: “Apple M…” means Apple silicon.

Linux

  1. AppImage: make it runnable with chmod +x strata-*.AppImage, then open it.
  2. .deb: sudo apt install ./strata-*-linux-amd64.deb
